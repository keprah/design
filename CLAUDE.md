# Портфолио Ильи Андреева (keprah/design)

Статический сайт без сборщика: главная + 3 кейса, версии EN (корень) и RU (`ru/`). Публикуется через GitHub Pages из корня `main`. Илья говорит по-русски — отвечай ему по-русски.

## Как устроено
- `styles.css` — общие стили и главная; `case.css`, `case.js` — страницы кейсов; `site.js` — модалка «Get in touch», переключатель языка.
- `index.html`, `ru/index.html`, `cases/*.html`, `ru/cases/*.html` — **генерируются** скриптом `tools/build.py` (тексты EN/RU, разметка) и данными `tools/cases_en.json`, `tools/cases_ru.json`.
  Правки текста и разметки вносим в `tools/build.py` / JSON и запускаем `python3 tools/build.py`. Не правь сгенерированные HTML руками — перезапишутся. Стили правим прямо в CSS.
- Шрифты Geist и Playfair Display лежат в `fonts/` (woff2, без внешних запросов). Картинки кейсов: `assets/cases/` в репозитории пусто, страницы берут их с `keprah.github.io/portfolio` через `data-remote`. `fetch-images.sh` скачивает их локально.

## Макеты и брейкпоинты
Десктоп ≥960 — Home_1440 (3 колонки), планшет 600–959 — Home_768, мобильный ≤480 — Home_390. Между 390 и 768 размеры шрифтов и главные отступы интерполируются через `clamp()`.
- Ручные переносы в тексте: `<br class="br-d|br-w|br-t|br-m">` — виден на десктопе (≥960) / широком (≥1232) / планшете (600–959) / мобильном (385–480); в остальных диапазонах текст переносится сам.
- Размеры шрифтов главной — токены `--fs-home-*`. Правила только для главной пишем с `body:not(.case-page)` или `.cases …`, чтобы не задеть страницы кейсов.

## Проверка перед публикацией
```
python3 tools/build.py
python3 tools/tests/make_test_copy.py      # копия в /tmp/site-test с картинками-заглушками
python3 tools/tests/btest.py               # модалка, язык, ссылки (ожидаем FAILED: [])
python3 tools/tests/rtest2.py              # переполнение на 13 ширинах (ожидаем issues 0)
python3 tools/tests/shift_test.py          # контент не сдвигается при открытии модалки
```
Нужны Python 3, Playwright и Chrome (`/usr/bin/google-chrome`).
