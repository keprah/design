About the project

I designed the financial monitoring section of a management panel for a real estate development project. The tool had to help the finance team work with a large set of metrics, compare planned and actual values, analyze variances and switch quickly between different data slices.

The interface’s main job was to make complex financial reporting clear, manageable and suitable for everyday use.

Key UX challenge: plan versions

In financial reporting, planned values can be updated, recalculated and used in different analysis scenarios. Users need to know which version of the plan they are comparing actuals against, and to switch between versions quickly.

I designed the version selection logic, the active-state display and the comparison scenarios so that this complexity stays manageable.

What mattered

  • Separate a quick overview from deep analysis.
  • Make the metric structure clear without overloading the screen.
  • Design filters, toggles and states for different comparison scenarios.
  • Present variances in a form that is easy to analyze.
  • Keep interaction patterns consistent across dashboards and tables.
  • Prepare the interface for large volumes of data.

Prototype

I presented all work at client meetings as interactive prototypes, then shared the links so the team and the client’s staff could test them internally.

Process

  • Analyzed requirements and financial reporting workflows.
  • Structured metrics, slices, filters and comparison options.
  • Designed the logic of dashboards, tables and detail views.
  • Worked out scenarios for selecting planned data versions.
  • Built interactive prototypes to validate the interface logic.
  • Refined the screen structure based on team discussions.
  • Prepared mockups and interface states for developer handoff.
